【硬件到货前的准备清单】

配件下单了，等货的这段时间可以先把这些做好，
到货当天就能直接开始测，不用临时到处找东西。

━━━━━━━━━━━━━━━━━━━━━━
■ 1. 下载并保存代码
━━━━━━━━━━━━━━━━━━━━━━
要一起拿走的：
  · code-project-1/          整个项目
      ├ src/                 18 个代码文件
      ├ data/sounds/         5 条占位音效
      ├ platformio.ini       构建配置
      └ partitions_8mb_ota.csv  分区表
  · 根目录的 note-*.txt      这些贴纸（不在项目文件夹里！）

不用下载：.pio/ 目录（编译中间产物，又大又没用）

━━━━━━━━━━━━━━━━━━━━━━
■ 2. TF 卡
━━━━━━━━━━━━━━━━━━━━━━
  · 8~32GB 都行，class 10
  · ★ 格式化成 FAT32
    （32GB 以上的卡默认是 exFAT，固件读不了，要用工具重格）
  · 卡里建目录：/sounds
  · 把音频 wav 放进去

━━━━━━━━━━━━━━━━━━━━━━
■ 3. 真实驱赶音效（这个最花时间，建议先弄）
━━━━━━━━━━━━━━━━━━━━━━
固件要求：16kHz / 单声道 / 16bit PCM WAV
用 ffmpeg 转换：

  ffmpeg -i 鹰叫.mp3 -ar 16000 -ac 1 -c:a pcm_s16le hawk_scream.wav

按目标动物准备：
  · 乌鸦 / 喜鹊  → 猛禽叫（鹰、隼）、同类惊叫
  · 野猪 / 狍子  → 狗吠、人声吼叫、低频重击
  · 通用         → 鞭炮声、警报声

★ 至少各准备 3~5 条轮换 —— 乌鸦喜鹊是鸦科，极聪明，
  固定一个声音叫几天它们就不怕了。

现有 5 条占位音效是合成的，只够验证链路，真驱赶要换掉。

━━━━━━━━━━━━━━━━━━━━━━
■ 4. 电脑上要装的东西
━━━━━━━━━━━━━━━━━━━━━━
  · 串口驱动：CH340 或 CP2102
    （看板子上的 USB 芯片型号，装错了电脑认不出串口）
  · Python 3 + paho-mqtt     → 用来模拟云端下发策略
      pip install paho-mqtt
  · ffmpeg                   → 转换音频格式
  · （可选）VS Code + PlatformIO 插件，想自己编译才需要

━━━━━━━━━━━━━━━━━━━━━━
■ 5. 手上要有的东西
━━━━━━━━━━━━━━━━━━━━━━
  · 一根【能传数据】的 USB 线（纯充电线认不出串口，最常见的坑）
  · 万用表 —— 第四阶段测功耗必须用，电流档要能测 µA
    没有的话现在就买，几十块
  · 小十字螺丝刀、镊子

━━━━━━━━━━━━━━━━━━━━━━
■ 6. 到货当天的顺序（重要）
━━━━━━━━━━━━━━━━━━━━━━
不要一上来就把所有模块插满！按这个顺序：

  ① 只插 USB 线，什么都不接
     → 看串口有没有开机日志
     → 这一步是确认"板子 + 驱动 + 串口"这条链是通的
  ② 烧录固件，听开机提示音（接 MAX98357 + 喇叭）
  ③ 加 TF 卡，串口敲 l 看能不能列出音频
  ④ 加 3 路 PIR，敲 s 看电平、用手挡着测触发
  ⑤ 加 WS2812，敲 w 测爆闪
  ⑥ 最后接电池和升压

每加一个模块测一次。一次全插上，出问题你根本不知道是哪根线。

★ 调试时先敲 z 关掉深度睡眠，否则 15 秒后它就睡了，
  串口没反应，你会以为死机。
