【BOM 调整清单 · 双感应驱赶节点（哺乳动物 + 鸟类）】

按你现有原型，改动集中在「传感器 / 供电 / 喇叭」三块。
主控、功放、音频链路不用动。

━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 一、必须换（3 项）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
1) 红外避障模块  →  PIR 人体感应 AM312
   原因：避障模块发射管常亮，静态 20~30mA，2000mAh 电池 3 天见底。
   AM312 静态约 15µA，同电池能撑约 100 天。

2) 供电 LDO  →  低静态电流型号（HT7333 / TPS7A02）
   原因：开发板上的 AMS1117 自己就吃 5mA，会把省下来的电全吃掉。
   深度睡眠实测经常是 1~10mA，而不是手册上的几十 µA。

3) 3W 普通喇叭  →  号角 / 高音喇叭（8Ω）
   原因：驱赶看声压级不看功率。号角喇叭灵敏度能高 15dB，
        比换更大功放划算得多。

━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 二、必须新增（因为要防鸟，这是新增需求）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
4) 微波雷达模块 —— 鸟必须靠雷达，PIR 对鸟基本无效
   · RCWL-0516（约 3mA，便宜）：动态功耗可接受，
     但要实测对小目标（喜鹊/乌鸦体型）的灵敏度
   · 海凌科 LD2410C（24GHz，灵敏度好）：工作电流 30mA+，
     不能常开，要做间歇供电（比如 2 秒开 1 次）
   ★ 先用便宜的 RCWL-0516 试，不够再上 LD2410C

5) 爆闪灯 / 高亮 LED + MOSFET 驱动
   鸟对强闪光非常敏感，而且纯靠声音会脱敏。
   大功率 LED 不能直接接 GPIO，必须用 MOSFET 驱动。

6) 音频素材（不是硬件但是必需品）
   猛禽叫声（针对鸦科）、狗吠、人声吼叫、低频轰鸣。
   多备几条随机轮换 —— 乌鸦喜鹊是鸦科，聪明且习惯化极快。

━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 三、太阳能供电（4 项）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
7)  太阳能板 5~6V / 2~6W
8)  CN3791 太阳能锂电充电模块
    ★ 不要用 TP4056：无 MPPT，且夜间会从电池倒灌
9)  18650 锂电池 ×2 + 保护板
10) 防水外壳 IP65 + 防水接头（野外紫外线会脆化普通塑料盒）

━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 四、联网（3 项）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
11) 4G Cat.1 模块：合宙 Air780E（约 ¥30~50，最好买）
    或 A7670C / EC200U
    ★ 不要上 5G 模组：贵且功耗大，我们只发小 JSON + 偶尔下几十 KB 音频
12) 物联网流量卡（几元/月）
13) 4G 天线（尽量竖起来，别贴地、别被金属壳挡住）

━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 五、保留不动
━━━━━━━━━━━━━━━━━━━━━━━━━━━
· ESP32-S3-N16R8 主控
· MAX98357 功放
· AHT10 温湿度（可选上报，判断是否进水/过热）
· LED 状态灯
· 面包板 + 杜邦线（调试阶段用）

━━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 六、双感应怎么配合（这条决定误报率）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
· PIR   → 哺乳动物（野猪 / 狍子 / 兔子），15µA 常开
· 雷达  → 鸟类 + 大动物，3mA 常开或间歇开

两种触发逻辑二选一：
  A. 任一触发就出声  → 不漏报，但风摇树枝会误触发（费电、扰民）
  B. 两个都触发才出声 → 误报低，但可能漏掉小鸟

建议先按 A 做（驱赶场景宁可误报不可漏报），
把冷却时间设长一点（比如 30 秒以上）来控制耗电和扰民。
