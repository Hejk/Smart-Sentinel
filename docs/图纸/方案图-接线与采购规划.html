接线怎么改 · 采购要不要现在做

结论先说：调试期一律插面包板别焊；主器件现在就能买；会变的只有接线件和几个小元件

▍三个阶段的接线方式（你现在在阶段 1）

1
面包板 + 杜邦线（插接）← 现在这里

改线 = 把线拔出来插到另一个孔，几秒钟，零成本、零风险。
工作台里画的接线就是这个形态，照着插就行。
只要还在调代码，就别焊。

2
洞洞板 / 面包板焊接（小批验证）

功能全通了、不再改线了，再焊到洞洞板上装盒子。
这一阶段改线要吸锡器 + 重新焊，比较烦。

3
自制 PCB（定型量产）

接线变成板子上的铜箔走线，改线 = 重新画板、重新打样。
只在前两阶段彻底稳定后才做。

▍采购建议

类别现在买?说明
ESP32-S3 / MAX98357 / 喇叭 / PIR / WS2812 / TF卡模块 / AHT10现在就买这些跟接线方式无关，只会继续用
18650 / TP4056 / 升压模块 / 太阳能板 / CN3791现在就买供电方案已经定了
面包板 + 杜邦线（公母各一把）多买消耗品，插拔多了会接触不良
MOS 管 / 二极管 / 电容 / 电阻 / 74AHCT125顺手加一点几块钱一堆，后面八成要用（灯带门控、电平转换）
4G 模块 Air780E + 流量卡可以等等等前面全部实测通了再上，先别让变量变多
微波雷达（补鸟用）先别型号还没定，先买 RCWL-0516 试灵敏度也行
改线在代码那边有多便宜？
所有引脚都集中写在 src/config.h 一个文件里，一共十几行 #define PIN_xxx。 你改完线，只改对应那几个数字，重新编译烧录就行 —— 其他代码一行都不用动。 这就是为什么我一直强调"改线请同步改 config.h"。

而且固件是"按功能"写的，不是"按引脚"写的： 换感应器（PIR → 雷达）、换存储（Flash → TF 卡）、换联网（WiFi → 4G）， 都是换一个模块文件，主逻辑不动。
建议的动手顺序： ① 先按现在的接线插到面包板上，把 1 → 3c 全部实测跑通
② 边测边记下"哪些线必须改"（比如功放 SD 要引 GPIO、灯带 5V 要串 MOS）
③ 等接线彻底不动了，再焊到洞洞板上装盒子
④ 焊完再测一轮，然后才考虑 PCB

★ 别反过来：先焊死再调代码，会把自己逼到每次改线都要动烙铁。
